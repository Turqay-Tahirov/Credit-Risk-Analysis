# Credit Risk Analytics Dashboard

## 📌 Layihə Haqqında (About the Project)
**AZ:** Bu layihə, bankçılıq və fintech sahəsində risk menecmentini optimallaşdırmaq üçün hazırlanmışdır. Müştərilərin demographics (yaş, gəlir, ev sahibliyi) və kredit göstəriciləri analiz edilərək, defolt (kredit gecikməsi) risklərini proqnozlaşdırmaq və vizuallaşdırmaq üçün interaktiv hesabat qurulur.

**EN:** This end-to-end analytics project focuses on credit risk management in banking and fintech. It analyzes borrower demographics and loan attributes to predict and visualize default rates for better decision-making.

---

## 🛠 Texnologiyalar (Tech Stack)
